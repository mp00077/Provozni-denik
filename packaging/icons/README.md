# Ikona Provozního deníku

Soubory: `app.png` (1024 px), `app.ico` (16–256 px), `app.icns` (macOS).
Kopie PNG v `src/provozni_denik/ui/resources/icons/app.png` slouží za běhu Qt.
Ikona byla vytvořena vestavěným nástrojem image_gen; PNG byla formátově převedena
pomocí Pillow se zachováním průhlednosti. Nevyžaduje síť při buildu.

Použitý prompt:

> Use case: logo-brand. Asset type: desktop application icon for a server-room access journal named Provozní deník. Create a polished square icon, a dark navy rounded-square tile containing a simple white server rack with three horizontal server units and a small teal access-check shield at its lower right. Bold clean silhouettes, readable at 16 to 256 pixels, flat professional appearance with restrained depth, centered with generous margin. No letters, no text, no watermark, no surrounding mockup. Transparent outside the rounded tile. Square 1024x1024.
